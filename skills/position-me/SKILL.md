# Position Me

Используй этот навык, даже если задача выглядит простой.

Turn a vague "what I do" into positioning a stranger understands in five seconds.

## Workflow

1. **Collect inputs.** Ask only for what is missing: who it is for, the problem solved, the result delivered, proof (numbers, clients, projects), what makes it different, tone. If the user gave a CV, site or profile, read it first and do not ask for what it already says.
2. **Pick one audience and one problem.** If the user lists several, choose the strongest by evidence and say why. Positioning that serves everyone serves no one.
3. **Write the core statement:**
   `For <audience> who <pain>, <name> is the <category> that <result>. Unlike <alternative>, <difference backed by proof>.`
4. **Derive assets** from the statement, never from scratch:
   - One-line headline (≤ 120 chars, LinkedIn/X)
   - Short bio (≤ 300 chars) and long bio (≤ 1200 chars), first person and third person
   - 3 proof points, each with a fact the user supplied
   - Elevator pitch (30 seconds, ≤ 80 words)
   - 3 content pillars that reinforce the position
5. **Self-check.** Remove every claim without evidence; never invent clients, numbers or awards. Delete buzzwords ("passionate", "innovative", "results-driven", "синергия"). If the `humanizer` or `stop-slop` skill is installed, run the final copy through it.

## Output

Return the core statement first, then the assets as headed sections, then a list of facts you still need from the user to make it stronger. Reply in the user's language.
